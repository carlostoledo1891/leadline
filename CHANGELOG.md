# Changelog

## 0.2.0 — 2026-11-10

- The metocean gallery: an environmental contour from virocon, a wave rose, a QQ plot, peaks over a threshold — public
  records fetched at their pins (`examples/data/fetch.py`), never committed.
- The guide, `docs/guide.html`: what does each number rest on? — the numbers of a metocean pipeline, one by one.
- `leadline.export`: report sizes and one call for SVG, PDF and PNG with the greyscale twin.
- Tests on GitHub Actions (Python 3.8–3.12; 3.7 allowed to fail), a release workflow for PyPI (trusted publishing), the
  docs redeployed on every push (Vercel, from `docs/`).
- `leadline.plotly.void` takes dates.

## 0.1.0 — 2026-11-10, the starter

- `leadline.mpl`: cert-machine's matplotlib kit (WARRANT v2.3, the print register), copied byte for byte and pinned.
- `leadline.plotly`: the same register for plotly — templates `warrant` and `warrant-grey`, the same helpers and refusals;
  legends and colour bars under the plot, read at 390 px.
- `leadline.fields`: a proposal — three field roles (magnitude `oslo`, difference `bam`, direction `bamO`) with the
  measurements behind them (`fields-report.json`).
- `tokens/leadline.tokens.json`: design tokens for Figma, generated.
- Four examples in both libraries; 29 checks with red controls.
